# 🌆 City Skyline

This project presents a stylized city skyline using **HTML** and **CSS**, emphasizing the use of CSS variables for efficient theming and design consistency.

## ✨ Features

- **Dynamic Design:** Utilizes CSS variables for easy theming and color adjustments.
- **Responsive Layout:** Ensures the skyline adapts to various screen sizes.
- **Layered Architecture:** Separates background and foreground buildings for depth.

## 📁 Project Structure

```
├── index.html   # Contains the HTML structure of the city skyline
└── styles.css   # Contains the CSS styles and variables
```

## 🚀 How to View

1. **Clone or Download:** Obtain the project files.
2. **Open `index.html`:** Use your preferred web browser to view the skyline.

## 🎨 Customization

- **Colors:** Modify the `:root` section in `styles.css` to change building and window colors.
- **Building Design:** Adjust dimensions and styles in the CSS to redesign buildings.

## 📚 Learning Objectives

This project is inspired by the [freeCodeCamp curriculum](https://www.freecodecamp.org/learn/2022/responsive-web-design/learn-css-variables-by-building-a-city-skyline/) and aims to help learners:

- Build complex layouts using HTML and CSS.
- Enhance responsive design skills.
