🌆 City Skyline
This project presents a stylized city skyline using HTML and CSS, emphasizing the use of CSS variables for efficient theming and design consistency.

✨ Features
Dynamic Design: Utilizes CSS variables for easy theming and color adjustments.
Responsive Layout: Ensures the skyline adapts to various screen sizes.
Layered Architecture: Separates background and foreground buildings for depth.

🚀 How to View
Clone or Download: Obtain the project files.
Open index.html: Use your preferred web browser to view the skyline.
🎨 Customization
Colors: Modify the :root section in styles.css to change building and window colors.
Building Design: Adjust dimensions and styles in the CSS to redesign buildings.
